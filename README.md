# ACP-XGBSV
It's the source code of paper "Anticancer Peptides Prediction Based on Two-level Classifier".

To train the model and output the results, run in the command line:
```
bash run.sh (for Linux)
run.bat (for windows)
```

The files in folder dataset are the training and testing data.

The features in folders csvTrainSet and csvTestSet can be generated using the following codes:
https://github.com/Superzchen/iFeature/  
https://github.com/Superzchen/iLearn  
https://github.com/agemagician/ProtTrans
